CONFIGURAÇÃO DO APPWRITE

settings
transactions
goals
accounts
categories
bills
cards

O projeto já tem endpoint, project ID e database ID preenchidos.

IMPORTANTE: o site público não deve conter API Key. A autenticação é feita pelo Appwrite Auth.
